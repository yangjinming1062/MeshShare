# 使用指南

## Android 运行环境

Android App 要求 Android 10 及以上和 Chromium 108 及以上的系统 WebView。出现版本提示时，更新设备的 Android System WebView 或提供 WebView 的 Chrome，然后重新打开 App。

## 设备与远程管理

「在线设备」按节点显示，同一设备的多个地址只占一行。节点握手版本必须一致，升级时请同时更新互连的桌面和 Android 节点。手动连接接受节点根地址或 `/mobile` 地址，并保存最近使用的地址。跨网络使用 Tailscale 时，自动发现要求至少一端能访问对端默认端口；双向传文件则要求双方都能访问对方的实际监听端口。

点击设备名称切换到目标节点，界面显示目标机器的剪贴板、传输、目录和设置。此前发往本机网页会话的文件会在对方确认后继续上传。如果另一设备接管原地址，界面会清空剪贴板草稿并暂停远程操作，重新找到同一节点后恢复。「返回本机」可随时退出管理。要从桌面节点的磁盘发送文件，先在目标机器开启远程文件访问，再浏览目标路径。若向目标节点的网页会话发送时出现升级提示，请先升级目标节点。

## 无界面 Linux 节点

从 Windows、macOS 或 Linux 桌面的「在线设备」点击服务名称，进入 NAS 的远程管理。文件浏览、发送和接收均使用 `meshshare-headless` 系统账户的权限。管理员应在 NAS 上为该账户授予目标目录的读写权限；它默认没有普通 NAS 用户私有文件的访问权。收件默认逐次确认，可在远程设置中指定目标机器上已有的目录并启用自动接收。

节点在没有桌面登录时仍保存文字和 PNG、维护历史并转发给其他已连接的节点。手机可访问节点地址的 `/mobile` 临时共享。桌面管理端可在该手机的会话卡片中选取 NAS 上的文件，手机确认后由 NAS 直接提供下载。桌面上的「目标终端」连接 NAS 服务账户；系统管理员仍可用原有的系统 SSH 维护机器。

「开机自启」只控制下次开机。「设置」中的「重启节点服务」会在文件准备、传输或终端占用时提示稍后重试。节点重新上线后，管理端按原节点身份恢复连接。服务已停止时可通过 SSH 执行 `systemctl start meshshare-headless`。

默认每周检查稳定版，支持每天、关闭和手动检查。在桌面点「立即检查」，或通过 SSH 执行 `meshshare-headless update`。安装会等待活动工作结束。用 `meshshare-headless status` 查看状态，`journalctl -u meshshare-headless -u 'meshshare-headless-control@*'` 检查服务与安装助手日志。需要手工恢复时，通过 SSH 以管理员身份重新安装保留的已知可用 headless deb，再运行 `systemctl restart meshshare-headless`。节点身份、CA、历史与设置保存在服务数据目录。迁移数据盘前须停止服务、复制完整目录并保留属主和权限，在 systemd 服务覆盖配置中设置 `MESHSHARE_DATA_DIR` 为新的绝对路径，再启动服务。接收目录单独设置。

## 桌面终端

在桌面或 Android App 的「在线设备」里，点击目标电脑旁的终端按钮即可连接。同一可信局域网或 Tailscale 中的其他设备可以用目标电脑当前的系统账号运行命令。新安装的桌面使用现有节点端口，无需配对或调整设置。在同一台电脑上使用终端，请从桌面主窗口打开本机终端。

已有桌面沿用本机保存的终端授权。曾关闭、仅允许配对，或只有旧凭据而未在本机确认的桌面会保留入站限制。需要开放远程终端时，在目标电脑主窗口的「设置」中点击「允许远程终端」。已在线设备会随即显示入口，确认结果在重启后继续有效。

设备离线时，目标电脑会结束该设备打开的远程终端。目标电脑重启并重新上线后，点击按钮会打开新的 shell。两端均需支持 v3 终端。

每个标签都有自己的 shell，从目标账号的主目录开始。Windows 打开 Windows PowerShell，macOS 和 Linux 打开该账号的登录 shell。桌面主窗口也可以独立打开本机终端。切换管理目标或隐藏窗口时，已打开的标签继续运行。

Android 可点击终端屏幕用软键盘输入，也可用 Ctrl+C、Tab、Esc 快捷键。返回设备列表时保留标签，点击页首的「终端」可回到会话。关闭标签会结束该 shell。断线后标签保留已显示的输出，重新连接会创建新 shell。退出 App 或重新加载主界面会结束该界面打开的会话。shell 的命令历史遵循目标系统配置。

## 剪贴板

- **同步与暂停。** 桌面自动收发文字和图片；「立即同步当前文字」发布编辑内容。暂停只阻止本机采集与主动发布，仍可收到其他节点的更新。
- **查找与恢复。** 「历史」可按文字预览、来源设备或类型搜索，不扫描全文。点选只预览，图片可放大；「恢复并同步」才发布所选内容。历史按条数或天数保留，清空历史不清除当前快照。
- **手机与网页。** 手动读取、编辑、发布文字或写回系统剪贴板。浏览器的系统剪贴板按钮需要安全上下文和权限；HTTP 页面可在文本框手动复制。
- **Linux 会话。** Wayland 优先使用 data-control，其次尝试 XWayland；两者都不可用时显示原因并重试。节点间共享与历史仍可用，系统剪贴板不能自动读写。

## 发送、接收与重试

| 操作 | 结果与限制 |
| --- | --- |
| 选择文件或拖到设备卡片 | 准备清单时可取消，不创建传输任务。Android 使用系统文件选择器，窄屏网页只提供文件发送。 |
| 确认接收 | 可每次选择目录，或对新任务使用自动接收。默认目录不可用时回到人工确认，已存在的同名文件不会被覆盖。 |
| 在 Android 保存 | 默认写入应用专属目录；授予「所有文件访问」后，新文件写入 `Download/MeshShare`。关闭 App 后节点停止。 |
| 在浏览器保存 | HTTP 使用浏览器默认下载位置，可逐项重下。需直写目录时，从「浏览器访问」下载并手动信任节点 CA，打开 HTTPS 地址，在支持目录选择的浏览器中授权。同名文件已存在时保存会停止。若浏览器无法打开写入流且目录中留下空文件，请核对文件后再重试。上传未完成时不要关闭页面。 |
| 失败后重试 | 从失败任务重试会跳过已提交文件；接收目录失效则重新选择。失败任务最多保留 20 条、最长 24 小时，可手动移除。 |
| 查找传过的文件 | 最近 10 条终态记录跨重启保留。桌面接收记录可定位落地项目，发送记录可打开来源目录；远程管理浏览目标目录，浏览器只显示路径。清空记录会同步删除对端的配对记录。 |

## 桌面监控与托盘

设备摘要可展开查看系统、内存、磁盘、网络和逐 GPU 指标。显存只计独立显存；不支持的指标和过期快照显示「—」，不当作零。悬浮条可拖动、锁定或隐藏；隐藏不停止采集，锁定后点击穿透（Wayland 不保证全局坐标、置顶或穿透）。

Windows、macOS 与 Linux X11 会在悬浮条所在屏幕出现可见全屏窗口时临时隐藏，退出全屏后恢复，不改变手动显隐偏好。普通最大化、无法区分的 macOS 窗口和 Wayland 会话不触发全屏隐藏。Windows 显示器变化导致悬浮条离屏时，优先恢复有效位置，否则回到主屏右下角。

关闭桌面主窗口只隐藏；从托盘可重新打开，Windows 也可左键双击托盘图标。正式安装默认登录自启，重复启动只激活已有窗口。

## 应用更新

默认每周检查稳定版，可改为每天、关闭或立即检查。桌面和 Android 都在传输与终端会话结束后安装。Linux 系统包需系统授权，取消后保持「待安装」，AppImage 则替换自身。Android 在前台检查，默认仅在非计费网络下载，安装需要系统授权。
