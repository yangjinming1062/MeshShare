# MeshShare 产品设计

## 体验目标

桌面程序常驻运行，让用户在不同系统的电脑之间继续使用刚复制的内容。Android App 在需要传资料时打开，关闭后不保持连接；其他设备的浏览器通过节点地址临时加入。传文件时收发两端同时在线，保存位置由接收方决定。

## 操作反馈

设置、剪贴板、连接和传输结果用底部短暂提示反馈，自动消失、可点击关闭；新提示替换上一条并重新计时。窗口在后台时系统会延后定时器，回到前台按剩余时间重排，不会留下过期提示。耗时步骤（例如发送前的摘要）改用传输列表里的准备行。

## 桌面端

主窗口按行显示在线设备与对端 CPU、内存、GPU 和速率摘要；点击设备进入远程管理，返回一步回到本机。远端硬件详情分系统、内存、网络、磁盘和 GPU 展示，暂未采集的字段显示占位，过期快照不展示旧值。

关闭主窗口只隐藏；Windows 下左键双击托盘图标切换显隐，其他平台通过托盘菜单操作。进入远程节点后，剪贴板、历史、设备、硬件、传输和设置都从目标读取，写操作也在目标执行；目标只有一层，离线时显示重连，返回本机不受影响。远程接收使用目标机器上的路径或目标已配置的默认目录，本机目录选择器不会被当成远程目录。

正式安装包默认开机自启，登录后以后台托盘模式启动；重复打开只激活已有窗口。自动更新默认每周检查稳定版，可改为每天或关闭；有传输时等待任务完成，安装窗口内的新传输提示稍后重试；Linux 系统包需要系统授权，取消后显示「待安装」并稍后重试，AppImage 直接替换自身。更新失败时节点继续运行并显示原因；本机更新代理只作用于更新请求。

共享剪贴板显示最新内容与本机历史。桌面复制后自动发布，也可编辑后「立即同步当前文字」。历史按内容去重，文字与 PNG 都保留；点击先预览，图片可放大，「恢复并同步」才写回系统剪贴板并广播。暂停同步会阻止本机采集与主动发布，其他节点仍可更新本机。自动发现依赖局域网组播；手动输入地址后建立带心跳和重试的连接，并保存最近地址。

## Android App

- 打开后启动本机节点，通过局域网 HTTP/WebSocket 连接桌面；保存最近地址，也支持 mDNS 和手动输入，不需要扫码、配对或安装本地 CA。
- 普通全隧道 VPN 下只要 Wi‑Fi 或以太网可用就优先使用物理局域网，Tailscale 组网保持 Tailscale；关闭 App 停止节点。
- 可查看桌面节点的 CPU、内存、GPU、显存和网络摘要与完整快照，本机只显示上下行速率。
- 发送使用系统文件选择器；接收默认写入应用专属目录，授予「所有文件访问」后改为公共 `Download/MeshShare` 并显示实际位置。
- 与网页共用移动版式：顶部固定节点名称与连接状态，待接收请求固定在首页顶部，手机宽度只提供文件发送。
- 更新在前台首次检查，之后默认每周，可改为每天、关闭或立即检查；默认在非计费网络下载。
- 不自动读写系统剪贴板；App 内可手动读取、编辑、发布共享文字，或写回本机。

## 浏览器网页

- 「浏览器访问」用 IP 列出局域网和 Tailscale 地址并生成二维码；手机可扫码，加入后窗口自动关闭。
- HTTP 页面无需证书。需要选择目录直写时，下载并安装本节点 CA，桌面端显示保存路径和系统安装步骤。MeshShare 不自动写入系统信任库：私钥以明文保存在节点数据目录。
- 网页显示接入节点、在线设备、最新共享文字和历史；可编辑并同步，也可预览后恢复；保留设置只读。系统剪贴板按钮需要权限和安全上下文，HTTP 页面用文本框手动复制。
- 版式按视口宽度单列或双列，待接收请求固定在页面顶部。

## 文件传输

从设备卡片选择或拖放，发送端先逐项计算 SHA-256，再登记任务并显示准备行（可取消，且不会产生任务）。接收方确认目录后，发送端流式上传；每个节点可选择「每次确认」或「自动接收」，自动模式使用默认目录，目录不可用时回退确认。远程管理发送由目标机器读取原文件并直传，管理端只浏览目录和提交路径。网页端也能向在线节点发送文件和文件夹，并把接入节点列为目标。

| 场景 | 行为与恢复 |
| --- | --- |
| 桌面接收 | 任务由节点运行时保留，界面重载后恢复；接收目录由本机选择；自动接收只对新任务生效。 |
| 远程管理 | 设置、自启、更新和监控在目标机器执行；接收目录通过目标机器的目录浏览选择。 |
| 网页接收 | 会话只在接入节点有效；HTTP 逐项下载、可重试；HTTPS + CA 可选择目录并流式写入；空闲 90 秒清理。 |
| 中断与历史 | 未开始上传约 90 秒后失败，无进展按五分钟失败，发送端按项目退避重试。完成、拒绝、取消和失败写入传输历史（最近 10 条，跨重启）；失败任务保留 20 条、最长 24 小时，可重试或移除。 |

网页上传使用分块 SHA-256 和 `File.stream()`，不一次性读取整个文件。同名文件不会被覆盖，校验失败的任务标记为失败。

## 硬件监控

悬浮条默认在主显示器右下角，分两行显示 CPU、GPU、上传与内存、显存、下载；未锁定时可拖动，右键可锁定或隐藏，锁定后点击穿透。位置、锁定和显隐都会保存，主窗口和托盘都能切换。隐藏悬浮条不影响后台采集和指标共享。

点击设备行摘要查看对端 CPU、内存、交换分区、网络、磁盘和逐 GPU 详情与采样时间。显存只统计独立显存，共享与统一内存不折算，核显显示为空；过期快照显示「—」。

## 使用边界

- **网络信任。** 无账号也无令牌，只绑定回环、私网、链路本地和 Tailscale 地址。HTTP 不提供链路加密、完整性保护或同网认证，HTTPS+CA 只保护浏览器到节点的链路。
- **数据保留。** 历史按配置的条数或天数淘汰，相同内容只保留一条；历史不通过节点间 WebSocket 批量同步。硬件只保留最新快照；活动与失败任务随节点运行保存在内存，最近 10 条终态历史写入数据目录。
- **浏览器上传。** 网页上传的内容由页面的 `File` 对象提供，关闭页面后未完成的上传需要重新选择；桌面与 Android 由节点读取，不受影响。
- **Wayland。** 剪贴板优先使用 data-control，没有该协议时回退 XWayland；都不可用时显示原因并持续重试，此时共享仍可用，只是无法写入本机系统剪贴板。悬浮条可显示和拖动，但不保证全局坐标、置顶和点击穿透。
