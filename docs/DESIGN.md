# 使用指南

## 设备与远程管理

「在线设备」按节点显示，同一设备的多个地址只占一行。手动连接会保存最近地址。跨网络使用 Tailscale 时，自动发现要求至少一端能访问对端默认端口；双向传文件则要求双方都能访问对方的实际监听端口。

点击设备名称切换到目标节点；此时剪贴板、传输、目录和设置均属于目标机器。「返回本机」退出管理，即使目标离线也可返回。要从目标磁盘发送文件，先在目标机器开启远程文件访问；不要在管理端选择一个同名本地目录代替目标路径。

## 桌面终端

在 Windows、macOS 或 Linux 主窗口打开本机终端，或点击在线桌面设备旁的终端按钮。每个标签都有自己的 shell，从运行目标节点的用户主目录开始。Windows 打开 Windows PowerShell，macOS 和 Linux 打开该账号的登录 shell。标签名称标明所属机器。切换管理目标、离开终端视图或隐藏主窗口时，已打开的标签继续运行。

首次从 A 连接 B 时，请让两台桌面的 MeshShare 保持运行，并确保 A 能访问 B 显示的节点端口。

1. 在 B 打开「设置」，在「本机终端授权」中点击「管理授权」。开启「允许远程终端」，再点击「配对新设备」。
2. 在 A 的设备列表中打开 B 的终端。核对 A 看到的目标指纹与 B 本机显示的指纹，确认后继续。
3. 在 B 核对申请设备的指纹与 A 本机显示的指纹，然后批准。以后 A 可以直接连接 B。需要从 B 操作 A 时，在 A 上另行授权。

要立即断开 A 对 B 的访问，在 B 的「可操作本机的设备」中撤销 A。设备保留节点 ID 并更换密钥后，旧指纹保存在另一端的授权列表中。

- A 更换密钥，在 B 的「可操作本机的设备」中撤销 A。
- B 更换密钥，在 A 的「本机信任的目标」中撤销 B。

若两端都换钥，执行以上两项操作。清理后，在 B 重新打开配对窗口，从 A 发起连接并核对新指纹。

关闭标签会结束该 shell。远程链路中断时，原标签保留已显示的输出；重新连接创建新 shell。退出应用或重新加载主界面会结束该界面打开的会话。键入的命令和终端输出由当前会话传递，shell 自己的历史记录遵循系统配置。

远程功能需要当前用户能访问系统凭据库。Linux 需要桌面会话提供 Secret Service。凭据库不可用时，本机终端仍可使用。活动终端和文件传输都会让桌面更新推迟安装。

## 剪贴板

- **同步与暂停。** 桌面自动收发文字和图片；「立即同步当前文字」发布编辑内容。暂停只阻止本机采集与主动发布，仍可收到其他节点的更新。
- **查找与恢复。** 「历史」可按文字预览、来源设备或类型搜索，不扫描全文。点选只预览，图片可放大；「恢复并同步」才发布所选内容。历史按条数或天数保留，清空历史不清除当前快照。
- **手机与网页。** 手动读取、编辑、发布文字或写回系统剪贴板。浏览器的系统剪贴板按钮需要安全上下文和权限；HTTP 页面可在文本框手动复制。
- **Linux 会话。** Wayland 优先使用 data-control，其次尝试 XWayland；两者都不可用时显示原因并重试。节点间共享与历史仍可用，系统剪贴板不能自动读写。

## 发送、接收与重试

| 操作 | 结果与限制 |
| --- | --- |
| 选择文件或拖到设备卡片 | 准备清单时可取消，不创建传输任务。Android 使用系统文件选择器，窄屏网页只提供文件发送。 |
| 确认接收 | 可每次选择目录，或对新任务使用自动接收。默认目录不可用时回到人工确认，已存在的同名文件不会被覆盖。 |
| 在 Android 保存 | 默认写入应用专属目录；授予「所有文件访问」后，新文件写入 `Download/MeshShare`。关闭 App 后节点停止。 |
| 在浏览器保存 | HTTP 使用浏览器默认下载位置，可逐项重下。需直写目录时，从「浏览器访问」下载并手动信任节点 CA，打开 HTTPS 地址，在支持目录选择的浏览器中授权。上传未完成时不要关闭页面。 |
| 失败后重试 | 从失败任务重试会跳过已提交文件；接收目录失效则重新选择。失败任务最多保留 20 条、最长 24 小时，可手动移除。 |
| 查找传过的文件 | 最近 10 条终态记录跨重启保留。桌面接收记录可定位落地项目，发送记录可打开来源目录；远程管理浏览目标目录，浏览器只显示路径。清空记录会同步删除对端的配对记录。 |

## 桌面监控与托盘

设备摘要可展开查看系统、内存、磁盘、网络和逐 GPU 指标。显存只计独立显存；不支持的指标和过期快照显示「—」，不当作零。悬浮条可拖动、锁定或隐藏；隐藏不停止采集，锁定后点击穿透（Wayland 不保证全局坐标、置顶或穿透）。

Windows、macOS 与 Linux X11 会在悬浮条所在屏幕出现可见全屏窗口时临时隐藏，退出全屏后恢复，不改变手动显隐偏好。普通最大化、无法区分的 macOS 窗口和 Wayland 会话不触发全屏隐藏。Windows 显示器变化导致悬浮条离屏时，优先恢复有效位置，否则回到主屏右下角。

关闭桌面主窗口只隐藏；从托盘可重新打开，Windows 也可左键双击托盘图标。正式安装默认登录自启，重复启动只激活已有窗口。

## 应用更新

默认每周检查稳定版，可改为每天、关闭或立即检查。桌面在传输和终端会话结束后安装；Linux 系统包需系统授权，取消后保持「待安装」，AppImage 则替换自身。Android 在前台检查，默认仅在非计费网络下载；安装受系统授权限制。
