# 使用指南

## 连接设备

- 同一局域网内启动 MeshShare，设备会出现在「在线设备」中。同一节点即使有多个可用地址也只显示一次。找不到设备时，点击「+」输入对方的节点地址，支持根地址或 `/mobile` 地址。互连的原生节点需要使用兼容版本。
- 跨局域网可通过 Tailscale 地址手动连接。桌面和 Linux-headless 版可通过 Tailscale CLI 自动发现其他桌面和 Linux-headless 节点，探测使用默认端口 `37880`。文件双向直传需要两端都能访问对方的实际端口。
- 临时使用浏览器时，点击桌面的「浏览器访问」，扫码或打开显示的地址。网页可收发文件、使用接入节点的共享剪贴板。接入节点的设备列表会显示该网页会话。
- Android App 要求 Android 10 及以上、Chromium 108 及以上的系统 WebView。收到版本提示时，更新 Android System WebView 或提供 WebView 的 Chrome，再重新打开 App。

## 设备与远程管理

在桌面「在线设备」中，点击设备名称进入远程管理。页头显示目标节点和连接状态，剪贴板、传输、目录和设置均以目标设备为准。点击「返回本机」回到本机概览。

只想修改设置时，点击设备行的齿轮，核对弹窗中的节点名和实际连接地址。设置项随目标能力显示。断线时点击「重新连接」可重新查找同一节点并读取设置。

从目标桌面的磁盘发送文件前，需在目标电脑本机开启「远程文件访问」。接收目录可手动输入目标设备上的绝对路径，开启远程文件访问后也可直接浏览。目录读取失败时，可以点击「重试」。地址被其他节点使用时，远程操作会暂停，找到原节点后恢复。

## Linux-headless 版

下载 `meshshare-headless_版本_amd64.deb`。安装包在 Ubuntu 22.04 amd64 上构建，需要 systemd 249 或更高版本，其他依赖由包管理器检查。[GitHub Releases](https://github.com/yangjinming1062/MeshShare/releases/latest)

在只含一个匹配安装包的目录运行以下命令。

```bash
sudo apt install ./meshshare-headless_*_amd64.deb
```

首次安装会启动 systemd 服务。可从桌面进入远程管理，也可打开该节点的 `/mobile` 使用临时共享。节点保存并转发文字和 PNG，管理端可从服务器选择文件直发给设备或该节点的网页会话。

首次安装开放远程文件访问和终端，均以 `meshshare-headless` 系统账户运行。需要读写其他目录时，为该账户授予对应权限。「目标终端」打开服务账户的 shell。收到文件时默认逐次确认，选择服务账户可写的接收目录后可启用自动接收。

| 操作 | 入口 |
| --- | --- |
| 查看版本、地址和更新状态 | 在服务器运行 `meshshare-headless status`。 |
| 设置自启或重启 | 「开机自启」影响下次启动系统。在远程设置里点击「重启节点服务」，有文件准备、传输或终端会话时需等空闲后重试。服务已停止时，由管理员运行 `systemctl start meshshare-headless`。 |
| 检查更新 | 在远程设置点击「立即检查」，或在服务器运行 `meshshare-headless update`。 |
| 排查或恢复 | 用 `journalctl -u meshshare-headless -u 'meshshare-headless-control@*'` 查看日志。需恢复旧版本时，由管理员用 apt 重新安装保留的可用 deb，允许降级后重启服务。 |

状态目录默认是 `/var/lib/meshshare-headless`，保存节点身份、网页 CA、历史和设置。迁移时停止服务，完整复制目录并保留属主与权限，在 systemd 服务覆盖配置中将 `MESHSHARE_DATA_DIR` 设为新目录的绝对路径，然后启动服务。接收目录需单独设置。

## 桌面终端

桌面可从页头打开本机终端。桌面和 Android App 可从在线设备的终端按钮连接桌面或 Linux-headless 版。允许入站终端的节点接受同一局域网或 Tailscale 中已连接的原生设备，命令以目标系统账户执行。

新装桌面默认允许入站终端。升级后若目标桌面未显示终端入口，在目标电脑本机的「设置」中检查「允许远程终端」授权。此前关闭、仅允许配对或仅保留旧系统凭据的安装需要在本机确认后开放，确认结果会保留。两端的终端协议需兼容。

以标签上的「本机」或目标节点名确认命令执行位置。每个标签从目标账户的主目录打开独立 shell，Windows 使用 Windows PowerShell。Android 支持软键盘及 Ctrl+C、Tab、Esc 快捷键，返回设备列表后可从页首回到终端。关闭标签会结束该会话，断线后可查看已显示的输出，重新连接时会打开新 shell。

## 剪贴板

- **同步。** 桌面自动收发文字和图片，也可编辑并立即发布文字。暂停后停止本机自动采集和主动发布，仍可接收其他节点的更新。
- **历史。** 搜索范围为文字预览、来源设备和类型。点选可预览，点击「恢复并同步」才会发布。历史可按条数或天数保留，清空历史后当前内容仍可用。
- **Android 与网页。** 手动读取、编辑、发布文字或写回系统剪贴板。网页操作系统剪贴板需要安全上下文和浏览器授权。在 HTTP 页面可直接从文本框手动复制。
- **Linux 桌面。** Wayland 优先使用 data-control，随后尝试 XWayland。两者都不可用时仍可使用界面共享和历史，系统剪贴板自动读写暂停，界面会显示原因。

## 发送、接收与重试

| 操作 | 结果与限制 |
| --- | --- |
| 发送 | 桌面可选择文件或文件夹，也可拖到设备卡片。Android 使用系统文件选择器。准备时可取消。 |
| 接收 | 桌面和 Linux-headless 版可逐次选择目录，也可为新任务配置自动接收。默认目录不可用时回到人工确认，已有同名文件会保留。macOS 目录授权失效后需重新选择。 |
| 在 Android 保存 | 默认写入应用专属目录。授予「所有文件访问」后，新接收的文件存到 `Download/MeshShare`。退出 App 会停止节点。 |
| 在浏览器保存 | 默认使用浏览器下载，可逐项重新下载仍可用的文件。需直写目录时，从「浏览器访问」下载并信任节点 CA，打开 HTTPS 地址，在支持目录选择的浏览器中授权。已有同名文件时停止保存。网页上传期间请保持页面开启。 |
| 失败后重试 | 节点直传可从失败任务重试，已提交的文件会被跳过。接收目录失效时需重新选择。失败任务最多保留 20 条、最长 24 小时，可手动移除。 |
| 查看传输历史 | 最近 10 条结束记录跨重启保留。桌面可打开所在位置，远程管理浏览的是目标节点的目录。清空历史会同步删除支持该功能的对端记录。 |

## 桌面监控与托盘

点击设备的指标摘要可查看 CPU、内存、磁盘、网络和 GPU 详情。摘要中的显存取可读取的独立显存使用率最高值。暂不可读的指标显示「—」。

悬浮监控条可拖动和隐藏，支持的平台可开启点击穿透。Windows、macOS 和 X11 检测到同屏可见全屏窗口时会临时隐藏悬浮条，退出全屏后恢复。Wayland 悬浮条的位置、置顶和穿透取决于桌面环境。

桌面主窗口关闭后，节点继续在托盘运行。可从托盘或重新启动程序打开已有窗口，Windows 也可双击托盘图标。正式桌面版默认登录时启动。

## 应用更新

默认每周检查稳定版，也可选择每天、关闭或立即检查。安装会等待活动传输和终端会话结束。Linux 桌面系统包需要本机授权，取消后保持「待安装」。AppImage 可直接更新。Android 在前台检查，默认通过非计费网络下载，安装需系统授权。
